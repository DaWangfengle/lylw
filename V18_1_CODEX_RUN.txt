Purpose
-------
Run the V18.1 single-member experiment from scratch without changing the
registered scientific design.

V18.1 is not an ensemble. Inference must use exactly one checkpoint and one
residual expert.

The official UJI validation file is the only sealed one-shot external
confirmation set. Do not open, hash, preview, parse, count, summarize or inspect
that file before the final external command.

The formal run has five stages:

1. prepare
2. train-selection
3. calibrate-freeze
4. train-final
5. external

The fifth stage is irreversible.

======================================================================
D. STAGE 2 — TRAIN AND SELECT EPOCH
======================================================================

Run:

python -m fhm_dapp_tim.fhm_dapp.uji_v18_1_experiment train-selection --device cuda

This stage may load only:
- member_fit shard;
- early_stop shard;
- selection_refit shard.

It must not load:
- calibration shard during gradient training or epoch selection;
- official validation file.

Training law must remain leave-self-out:

L_joint =
  -sum_j q_ij [
    log p(anchor_j | scan_i)
    + log p(position_i | scan_i, anchor_j)
  ]

where j is a non-self Delaunay neighbour.

The true anchor must not receive positive geometry target mass.

The natural neural retrieval diagnostic must be computed before geometry target
forcing.

Epoch selection contract:
- epochs 1 through 11 are ineligible;
- eligible epochs begin at epoch 12;
- primary metric is coordinate-macro Energy Score;
- find the minimum eligible Energy Score;
- shortlist epochs within 0.05 m of that minimum;
- choose the lowest MAE in the shortlist;
- then lower Energy Score and earlier epoch break remaining ties.

NLL must NOT be the epoch-selection statistic.

Record the full per-epoch trajectory:
- total training loss;
- joint_geometry_loss;
- retrieval_nll;
- coordinate_nll;
- reranker_loss;
- hierarchy_loss;
- coordinate_loss;
- domain_loss;
- natural_geometry_recall_mass;
- early-stop MAE;
- early-stop Energy Score;
- early-stop mixture NLL;
- floor/building error;
- entropy;
- effective anchor count;
- top1 probability;
- radial scale;
- within/between uncertainty;
- nearest-anchor recall@8/16/32/64;
- predictive coverage 50/80/90/95.

Confirm:
- selected_epoch >= 12;
- selection checkpoint uses exactly one checkpoint contract;
- residual_experts == 1;
- all checkpoint tensors and history values are finite;
- no external validation access occurred.

If a genuine code bug is discovered before external access:
