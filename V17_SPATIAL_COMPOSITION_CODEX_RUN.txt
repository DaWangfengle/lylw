METHODS PER CHECKPOINT
1. joint_calibrated_base: clean T/theta calibration.
2. 1A_global: prior-only graph diffusion; alpha_obs fixed to zero.
3. 1D_global: separately selected prior and observation diffusion.
4. 2A: compact N+E Cell LSE using the beta selected by 2B and gamma_space=0.
5. 2B: compact N+E Cell LSE with beta/gamma_space selected on CAL-fit.
6. 2A_beta_only_control: best gamma-zero beta-only control.
7. combo_1A_2A, combo_1A_2B, combo_1A_2A_beta_only_control.
8. combo_1D_2A, combo_1D_2B, combo_1D_2A_beta_only_control.

Composition order must be exact:
- Fit clean T/theta on CAL-fit.
- Select 1A/1D alpha on CAL-fit and freeze those values.
- Select standalone 2A/2B beta/gamma on CAL-fit.
- For each combo, freeze the corresponding S1 alpha selected by its S1-only CAL-fit fit, then select beta/gamma conditional on the diffused physical-parent logits on CAL-fit.
- At inference, apply S1 to physical parent prior/observation channels first, then use those parent logits with the normal S2 virtual logits in compact Cell LSE.
- Virtual retrieval scores must use the existing interpolated neural key + FIT-only RSS-prototype distance law. Do not replace virtual logits with the average of endpoint complete logits.
- For E checkpoints, retain the saved training-time graph layer and alpha. Post-hoc S1 is an additional inference-time operator and must be recorded as such.
- Use global normalization for 1A_global/1D_global.
- Use the existing site-equal objective: joint BF-XY NLL + 0.30 component-center transport risk, with the existing deterministic grids and tie-breaks.
- Use the same CAL-eval rows and seed+900 Energy Score Monte Carlo seed across all methods in a run.
- Report MAE, ES, joint NLL, BF accuracy, P95/P99, worst-site MAE, paired site deltas, seed means/sample SD, selected parameters, and checkpoint/source/split hashes. Preserve negative results.
