Research scope
--------------
This is a bounded closeout experiment, not another model-design iteration.

Stage 1 compares only:
  1. raw_neighbors: the original V17 neighbor target;
  2. same_floor_neighbors: the same V17 training recipe with same-building,
     same-floor neighbor targets.

There is NO post-hoc Joint fine-tuning path in this experiment.

For every dataset and seed, both variants start from the exact same initialized
model state, use the same seed and DataLoader seed, and use the same optimizer,
loss weights, data roles, batch size, and 80-epoch budget. Each variant runs
all Epochs 1..80. The code contains no early-stop break in the training loop.

At every epoch, EPOCH_HISTORY.csv and RESULT.json record:
  - FIT total loss;
  - every component returned by AnchorStudentTModel.training_loss;
  - DEV site-macro MAE, predicted-BF-conditioned MAE, site-macro BF accuracy,
    row-level BF accuracy, and DEV site count.

The three checkpoint policies are reported side by side:
  (a) legacy_early_stop: replay the old rule exactly (>=0.01m DEV improvement;
      stop when epoch>=20 and epoch-best_epoch>=12), without interrupting the
      actual 80-epoch run;
  (b) best_dev_epoch_1_80: minimum raw DEV MAE over all 80 epochs;
  (c) best_dev_epoch_21_80: minimum raw DEV MAE over Epochs 21..80.

Policy (c) is predeclared as the only Stage-2 primary checkpoint. Policies (a)
and (b) are retained as checkpoint-selection sensitivity audits. CAL-eval is
never used to select a checkpoint.

Stage 2 freezes each primary Stage-1 model and its continuous components. On
the same site-disjoint CAL-fit/CAL-eval protocol, it evaluates:
  1. raw: T=1, theta=(0,0);
  2. temperature_only: fit free T in [0.25, 3], theta=(0,0);
  3. g13_fixed_t06: fix T=0.6 and fit the two G13 coefficients in [0,1.5];
  4. temperature_plus_g13: jointly fit free T and the two G13 coefficients.

Calibration fitting uses CAL-fit only. All four policies share exactly the
same candidate IDs, centers, and scales for a given frozen checkpoint.
Metrics are evaluated only on CAL-eval. No internal TEST role and no official
test labels are scored.

Datasets and paired seeds
-------------------------
Datasets: tuji, uts, uji
Seeds:    17301, 17302, 17303
Split seed: 20261017 (fixed across paired seeds)
CAL-fit split seed: 20261116 (fixed across paired seeds)
Default batch: 64
Default threads: 4
Energy Score Monte Carlo draws: 32

Before running
--------------
Use the same Python environment and repository-local data files as the previous
V17 runs. From the repository root, run:

  python -m compileall -q fhm_dapp_tim/fhm_dapp/msep_v17_two_stage_freeze_v1.py tests/test_msep_v17_two_stage_freeze_v1.py

  python -m pytest -q tests/test_msep_v17_two_stage_freeze_v1.py tests/test_msep_joint_ablation_v1.py

Do not proceed if either command fails. Fix only a reproduced implementation
bug, rerun both commands, and preserve the failure logs.

The default data root is the repository's existing data directory. The script
loads only the canonical training inputs:
  TUJI: data/TUJI1 through the existing train-only adapter;
  UTS:  data/UTSIndoorLoc/UTS_training.csv;
  UJI:  data/UJIndoorLoc/trainingData.csv.
Do not open or use official test/validation labels.

Run all nine paired dataset-seed jobs
-------------------------------------
PowerShell commands from the repository root:

  $root = "fhm_dapp_tim/evidence/v17_two_stage_freeze_v1"
  New-Item -ItemType Directory -Force -Path $root | Out-Null

  foreach ($dataset in @("tuji", "uts", "uji")) {
    foreach ($seed in @(17301, 17302, 17303)) {
      $out = Join-Path $root ("{0}_seed{1}" -f $dataset, $seed)
      $log = Join-Path $root ("{0}_seed{1}.log" -f $dataset, $seed)
      python -m fhm_dapp_tim.fhm_dapp.msep_v17_two_stage_freeze_v1 run --dataset $dataset --seed $seed --output $out --device auto --batch 64 --threads 4 --es-draws 32 *>&1 | Tee-Object -FilePath $log
      if ($LASTEXITCODE -ne 0) {
        Get-Content $log -Tail 80
        throw "Run failed: dataset=$dataset seed=$seed output=$out log=$log"
      }
    }
  }

The runner refuses to overwrite an existing output directory. If a run fails
after creating its directory, preserve that incomplete directory by renaming it
to a clearly marked *_failed_attemptN directory, inspect its stdout/stderr, then
rerun that dataset-seed into the canonical output path. Do not delete evidence
of a failed attempt. Do not change seeds, split seeds, epochs, loss weights,
checkpoint policies, calibration bounds, or the evaluation role in response to
an unfavorable score.

After all nine runs complete
----------------------------
  python -m fhm_dapp_tim.fhm_dapp.msep_v17_two_stage_freeze_v1 aggregate --root fhm_dapp_tim/evidence/v17_two_stage_freeze_v1

Aggregation requires all nine RESULT.json files and writes:

  AGGREGATE_SUMMARY.csv       dataset-level means and sample SD across 3 seeds
  AGGREGATE_SUMMARY.json      protocol and interpretation notes
  RUN_LEVEL_METRICS.csv       every seed x model/checkpoint/calibration result
  PAIRED_DELTAS.csv           paired seed-level deltas
  SITE_DELTAS_ALL_RUNS.csv    per-physical-site changes for every paired contrast

Each run directory contains:
  RESULT.json
  SITE_DIAGNOSTICS.json
  EPOCH_HISTORY.csv
  CHECKPOINT_SELECTION.csv
  RUN_MANIFEST.json
  REFERENCE_STATE.pt (FIT reference geometry, AP IDs, observation memory, and role keys)
  six checkpoint files (three policies x two neighbor variants)

Interpretation conventions
--------------------------
- Negative MAE or Energy Score delta means improvement.
- Positive BF-accuracy delta means improvement.
- Stage-1 same-floor deltas compare same_floor_neighbors against raw_neighbors
  on the same CAL-eval sites, for each checkpoint policy.
- Stage-2 calibration deltas compare each calibrated posterior against Raw for
  the same frozen model and same CAL-eval sites.
- TUJI is expected to be a same-floor no-op when its FIT reference anchors all
  share one building-floor stratum. The runner asserts that the neighbor IDs and
  weights are identical in this case.
- The three seeds share evaluation sites; report their mean and sample SD as
  paired-seed variability, not as three independent datasets or a formal
  significance test.
- A lower MAE alone is not sufficient: inspect Energy Score, BF accuracy, and
  per-site regressions together.
- This is an internal CAL-eval closeout, not a fresh blind official-test result.
