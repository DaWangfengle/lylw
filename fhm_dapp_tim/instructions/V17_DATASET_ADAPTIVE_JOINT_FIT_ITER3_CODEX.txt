2. Compile and run targeted tests
---------------------------------

  python -m py_compile fhm_dapp_tim/fhm_dapp/msep_v17_dataset_adaptive_joint_fit_v1.py

3. Run FIT-only preflight into the fresh iter3 directory
-------------------------------------------------------
Run:

  python -m fhm_dapp_tim.fhm_dapp.msep_v17_dataset_adaptive_joint_fit_v1 preflight --output fhm_dapp_tim/evidence/v17_dataset_adaptive_joint_fit_iter3

Preflight must finish successfully before any dataset run. Inspect:
- FIT_NEIGHBOR_DISTANCE_DIAGNOSTICS.md
- SPATIAL_SCALE_SEARCH_SPACE.json

Expected geometry design for every dataset × seed:
- exactly 12 geometry configurations;
- R_max_S1 comes only from the actual union-kNN edge P75/P90/P95/P100 values;
- R_max_S2 comes only from the actual union-kNN edge P50/P75/P90/P95/P100 values;
- finite tau_graph and tau_virt come only from FIT k=1/2/4/8 neighbor P50 and edge P50/P75/P90;
- tau_virt=+infinity is present as a no-distance-decay control;
- R_max_S2 <= R_max_S1;
- no cutoff exceeds the actual edge P100;
- every S1 graph retains at least one base edge;
- every S2 graph retains at least ceil(0.45 * base_union_knn_edges) edges;
- each geometry records actual retained S1/S2 edge counts and fractions.

There should be nine dataset/seed geometry sets across TUJI, UTS, and UJI. The preflight
must validate actual edge distances, not merely trust the quantile labels. If any set
fails, stop and report the dataset/seed, geometry_id, radius, actual retained counts,
and exception. Do not start TUJI until the full preflight passes.
