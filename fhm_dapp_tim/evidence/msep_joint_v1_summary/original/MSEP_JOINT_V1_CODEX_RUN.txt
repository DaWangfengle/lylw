特别检查：
- 自适应同楼层邻居的单锚点楼层、样本稀疏楼层是否正确处理，softmax 不出现 NaN，零权重不得跑到错楼层。

- 每个 CAL-eval 站点都未落入 CAL-fit，同一个物理位置的全部扫描仅分一个角色。
- 原基准与新研究数据编码器接口一致，所有 AP mask/原型信息仅由 FIT 构造。
- 旧 XY Joint 作为负对照不加入 BF 监督；新 BF-XY 同步报告 full XY mean 与 model-predicted BF conditioned XY mean。

四、三域正式开发期实验：三个预设训练种子（不是官方/独立 TEST）
$PY = 'D:\miniminiconda\envs\liuyan\python.exe'
$seeds = @(17301, 17302, 17303)
$domains = @('tuji', 'uts', 'uji')
foreach ($seed in $seeds) {
  foreach ($domain in $domains) {
    $out = "fhm_dapp_tim/evidence/msep_joint_v1_${domain}_seed${seed}"
    $cliArgs = @('-m','fhm_dapp_tim.fhm_dapp.msep_joint_ablation_v1','--dataset',$domain,'--seed',[string]$seed,'--split-seed','20261017','--base-epochs','80','--joint-epochs','10','--batch','64','--es-draws','32','--output',$out)
    if ($seed -eq 17301) { $cliArgs += '--save-checkpoints' }
    New-Item -ItemType Directory -Force -Path $out | Out-Null
    & $PY @cliArgs 2>&1 | Tee-Object -FilePath (Join-Path $out 'RUN_STDOUT_STDERR.log')
    $code = $LASTEXITCODE
    if ($code -ne 0) { throw "FAILED $domain seed $seed exit $code; preserve logs; do not conceal or skip" }
  }
}
